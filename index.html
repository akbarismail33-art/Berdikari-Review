Panduan Aplikasi BERDIKARI REVIEW v1.0

Alur kerja lengkap pembuatan konten storyboard hingga penggabungan video di CapCut.

1

Pengaturan & Test Koneksi API Key

Klik tombol API Key di atas sidebar. Jika Anda memakai aplikasi di GitHub Pages atau file lokal di HP Android, masukkan Gemini API Key dari Google AI Studio lalu klik Test Koneksi API untuk memastikan kunci aktif.

2

Multi-Foto Referensi (1–4 Foto)

Unggah 1 hingga 4 foto wajah model dari berbagai sudut atau simpan karakter AI ke Pustaka Model agar hasil generasi gambar vertikal 9:16 mempertahankan kemiripan wajah secara konsisten.

3

Analisa Produk Otomatis & Bahasa Tersirat

Pada menu Review Generator, cukup unggah foto produk. AI otomatis membaca detail kemasan, merangkum keunggulan dengan bahasa tersirat yang aman dari overclaim medis/kebijakan afiliasi, dan memilih latar paling cocok untuk 1 hingga 10 scene.

4

Animasi & Gabungkan di CapCut

Unduh semua gambar klip 9:16, salin Prompt Video untuk menganimasikan gerakan bibir (*lip-sync*), lalu satukan klip-klip tersebut di CapCut menjadi satu video monolog utuh.
